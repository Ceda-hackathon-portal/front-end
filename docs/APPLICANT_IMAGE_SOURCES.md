# Applicant portal imagery

The portal shares one edge-to-edge hero layout. Page titles are functional labels, without promotional slogans. The header and profile controls sit over each hero. The original image files are retained; CSS lowers saturation and adds a light warm tone and contrast overlays to fit CEDA's palette. No generative image editing is used.
